Conexão e aplicativo

Endereço do Apps Script e instalação do GABAgenda.

Como publicar
  1. Na planilha: Extensões › Apps Script › cole o code.gs e execute setupCompleto.
  2. Implantar › Nova implantação › App da Web › Executar como Eu, acesso Qualquer pessoa. Copie a URL /exec.
  3. No GitHub, coloque index.html e arquivo.js na raiz do repositório e ative o GitHub Pages.
  4. Para todos usarem o mesmo endereço sem configurar, cole a URL na constante URL_APPS_SCRIPT do index.html.
